01 — Alapok

Mi az a Skill?

Képzeld el, hogy minden egyes projektnél elmagyarázod az AI-nak, hogyan dolgozz. A skill ennek a fordítottja: egyszer leírod, és többé nem kell.

📋

Egy Markdown fájl

A skill lényegében egy SKILL.md — utasítások, kontextus és példák, amit Claude minden aktiváláskor olvas.

🎯

Trigger feltétel

Meghatározod, mikor fusson le — parancsszóra (/ace-step), témára, vagy automatikusan, ha a kontextus megfelel.

⚡

Újrafelhasználható tudás

Egy skill-t bármely projektben, bármikor bevetethetsz. Nem kell újra elmagyarázni. Mások skilljeit is telepítheted.

🧩

Mappa + scriptek

A skill nem csak egy fájl: lehet alatta scripts/ (Python, Node, shell), sablonok és példák. A Claude Code ügynök ezeket írja és futtatja a SKILL.md utasítása szerint — a Cursor ügynök ugyanígy.

02 — Hogyan működik

A kérés útja

Amikor beírsz egy kérést, Claude nem vakon válaszol. Ellenőrzi, hogy van-e skill, ami releváns — és ha igen, először azt olvassa el.

1
Te

Beírsz egy kérést

„Írj nekem egy Substack cikket a produktivitásról" — vagy csak elindítasz egy projektet.

2
Skill rendszer

Claude ellenőrzi az elérhető skill-eket

A rendszer megnézi, hogy a kérésed illeszkedik-e valamelyik telepített skill trigger feltételéhez.

3
Skill

Beolvassa a SKILL.md-t

Ha talál egyező skill-t, elolvassa az instrukciókat, a kontextust és a példákat — ez lesz az „agymenete".

4
MCP

Szükség esetén külső eszközt hív

Ha a skill MCP-t használ (pl. Substack API, Suno), Claude közvetlenül kommunikál ezzel a szolgáltatással — te nem csinálsz semmit.

5
Eredmény

Szakértői szintű kimenet

A skill tudásával felvértezve Claude pontosan azt csinálja, amit egy tapasztalt szakember csinálna — első körben.

04 — Skill felépítése

Így néz ki egy SKILL.md

A Magyar Humanizer skill valódi kódja — egy fájl, ami megtanítja Claude-ot arra, hogyan tegyen emberibbé egy AI-szöveget.

SKILL.md 
---
name: magyar-humanizer
version: 1.4.1
description: >
  AI-szag eltávolítása
  magyar szövegekből.
---

# Magyar Humanizer

## A feladatod

Amikor szöveget kapsz:

1. Azonosítsd az AI-mintákat
2. Írd át természetesen
3. Adj lelket — nem csak
   tisztítsd, hanem töltsd fel

## Minták

❌ "kulcsfontosságú tényező"
✅ mondd el konkrétan

❌ "Fontos megjegyezni, hogy"
✅ töröld — kezdj rögtön

## Ritmus

Rövid mondat.
Aztán hosszabb, ami elvisz valahova.
Megint rövid — ez az ütés.
1

Frontmatter (YAML fejléc)

Név, verzió, leírás — ez jelenik meg az elérhető skill-ek listájában.

2

Szerep meghatározása

„Te egy szövegszerkesztő vagy…" — a skill azonnal szerepet ad Claude-nak.

3

Lépésről lépésre feladat

Minden skill tartalmaz egy számozott folyamatot. Claude pontosan ezt követi.

4

Előtte / Utána példák

A legjobb skillek konkrét példákkal tanítanak — nem elvont szabályokkal.

5

Eszközök (opcionális)

MCP, külső API, helyi CLI — és a skill mappában lévő saját scriptek, amiket az ügynök a terminálon futtat (pl. validálás, HTML-jelentés, adatfeldolgozás).

6

Csomagolt scriptek (.py, .js, .sh)

Claude Code és Cursor képes a skill könyvtárban új vagy meglévő segédfájlokat szerkeszteni. A SKILL.md leírja, mikor melyik scriptet hívja. Claude Code-ban a ${CLAUDE_SKILL_DIR} változó mindig a skill mappa útvonalára mutat.

A humanizer skill hatása

❌ Skill nélkül (AI-szöveg)

A mesterséges intelligencia egyre nagyobb szerepet játszik a modern vállalatok működésében. Fontos megjegyezni, hogy a technológia alkalmazása kulcsfontosságú tényező a versenyképesség szempontjából. Szakértők szerint az átállás folyamata komplex feladatot jelent.

✅ Magyar Humanizer skill után

Az AI nélkül ma már nehéz versenyezni — ez nem kérdés. A valódi kérdés az, hogy a bevezetés hogyan történik. A Gartner 2023-as felmérése szerint a munkavállalók 60%-a soha nem kapott rendszeres AI-oktatást. Aki erre nem költ, az pár éven belül megérzi.

05 — Scriptek a skillben

Saját kód a skill mappában

A SKILL.md csak a „recept”. A hozzá tartozó Python-, JavaScript- vagy shell-scripteket maga a Claude Code vagy Cursor ügynök készítheti el és tarthatja karban — te vagy a create-skill workflow irányítja. Így a skill nemcsak szöveget ad az AI-nak, hanem konkrét futtatható lépéseket is.

Python Node.js Bash / shell bármilyen CLI
my-skill/ · könyvtárstruktúra
my-skill/
├── SKILL.md          # kötelező — fő utasítások
├── reference.md     # részletes docs (igény szerint betöltve)
├── examples/
│   └── sample.md
└── scripts/
    ├── validate.py   # ellenőrzés / ETL
    ├── build_report.js
    └── deploy.sh

Claude Code hivatalos példája: egy skill allowed-tools: Bash(python *) frontmatterrel engedélyezi, hogy futás közben meghívja a csomagolt scripts/visualize.py-t — például interaktív HTML jelentést generáljon a kódbázisról.

Cursor a create-skill útmutató szerint ugyanezt a mappa-elrendezést javasolja (~/.cursor/skills/ személyi, .cursor/skills/ projekt szinten). Az ügynök a fájlokat szerkeszti és a megfelelő eszközzel futtatja — nem kell külön MCP minden apró segédfüggvényhez.

SKILL.md · részlet (Claude Code stílus) 
---
name: data-pipeline
description: CSV tisztítás és riport
allowed-tools: Bash(python3 *)
---

Futtasd a skill scriptet a repo gyökeréből:

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/clean_csv.py $ARGUMENTS
```

06 — Kutatás

Mit tud még a skill rendszer?

Összefoglaló a Claude Code hivatalos dokumentációjából és a Cursor skill-útmutatójából (2026 eleje). Részletes linkek és források: lásd a repóban a RESEARCH.md fájlt.

📜 Nyílt szabvány

A Claude Code skillek az Agent Skills szabványt követik — több eszköz között is hordozható formátum.

📂 Támogató fájlok

Sablonok, reference.md, példagyűjtemények: a SKILL.md rövid marad (<500 sor ajánlott), a részletek külön fájlban.

⚡ Dinamikus kontextus

Claude Code: !`parancs` szintaxis — shell kimenet beillesztése a skill szövegébe mielőtt az AI látná (pl. gh pr diff).

🔀 Subagent

context: fork + agent: Explore (vagy más): a skill izolált ügynökben fut, más eszközkészlettel.

🎛️ Frontmatter vezérlés

  • disable-model-invocation — csak te hívod /skill-lel
  • user-invocable: false — csak a modell tölti be
  • allowed-tools — engedélyezett eszközök szűrése
  • model, effort — modell és „erőfeszítés”

📥 Argumentumok

$ARGUMENTS, $0, $1… — slash parancs mögé írt szöveg beépül a skillbe.

🏢 Monorepo

Beágyazott packages/foo/.claude/skills/ automatikus felfedezése — csomagonként saját skillek.

🎁 Beépített skillek

Claude Code: pl. /batch (párhuzamos worktree PR-k), /loop, /simplify, /claude-api — playbook + eszközök.

🔌 Terjesztés

Projekt skill (git), plugin skill, enterprise managed settings; --add-dir extra könyvtárakból is betöltés.

🪝 Hooks

Skill- és agent-életciklushoz kötött hookok (Claude Code hooks dokumentáció).

🖱️ Cursor

Személyi ~/.cursor/skills/ vs projekt .cursor/skills/. A ~/.cursor/skills-cursor/ a beépített skill-eknek van fenntartva.

Források: Claude Code — Skills · agentskills.io · Cursor: beépített create-skill útmutató (SKILL.md + scripts/ mappa).
